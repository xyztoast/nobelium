Documentation

Everything Nobelium can do. Statements run top to bottom. Comments start with //. Selectors are strings.

Events

when EVENT "selector" { ... } runs the block when the event happens on a matching element. It also works for elements added to the page later.

eventmeaning
clickelement clicked
hover / leavepointer enters / leaves the element
inputtyping in an input
submitform submitted
keypressany key pressed (when keypress { }, no selector). Use event.key
key "Escape"one specific key, anywhere on the page
loadruns right away when the page is ready (when load { })

Inside a block, event has type, key, value and text.

Statements

show "#a"make visible. Also hide and toggle
fade in "#a"fade in (or fade out), 0.3 seconds
add class "x" to "#a"also remove class "x" from "#a" and toggle class "x" on "#a"
set text "#a" to exprchange text. set value changes an input
let x = exprnew variable. Change it later with x = expr
if cond { } else { }also else if. Blocks nest
repeat 3 { }run a block several times (max 10000)
fn name(a, b) { }function. return expr gives a value back
wait 500mspause (1s works too)
get "url" into datahttp request. Json becomes an object, read with data.title
stopcancel the browser default (like a form really submitting). Put it before any wait or get
log exprprint to the console panel / browser console

Expressions

Numbers, strings, true false null, variables, ( ), + - * / %, == != < > <= >=, and or not. + joins text if either side is text. value of "#input" and text of "#el" read the page. Empty text, 0, false and null count as false.

built-in functions

len(x)length of text or list
upper / lower / trimtext helpers
contains(a, b)true if text a includes b
num(x) str(x) round(x)conversions
random(a, b)whole number from a to b
item(list, i)list item (starts at 0)
exists("#a")true if the element is on the page

Errors

Syntax errors are reported with a line number and that block does not run. Runtime errors (missing element, unknown variable, failed request) are reported and only stop the one handler. The rest of the page keeps working. Errors go to the browser console, or the playground console.

Files

.nobelium is the main extension and .nbm is the short one. Load either with <nobelium src="file.nbm"></nobelium>. Multiple blocks per page are fine and share nothing except the page itself.

Safety

Nobelium is interpreted by walking its own syntax tree. There is no eval, no Function, and objects only expose their own fields.
